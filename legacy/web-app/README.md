# Legacy web app (Express API era)

The first prsnn web app: login, bookings, admin and super-admin pages that talked to the old Express +
MongoDB API (`NEXT_PUBLIC_API_URL`). That API is retired (the app and admin now run on Supabase in
`prsnn-mobile`), so these pages are no longer deployed. The code and its tests are kept here for
reference; the public website is `app/(site)`.
